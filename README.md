# 黄焖鸡 AI 助手 Demo

基于 `PPT` 功能说明实现的 `Web 交互式 Demo`，包含：

- 待办任务汇总与任务执行
- 门店知识库管理
- 经营分析与 AI 结论生成
- 库存预警与采购清单导出
- 文字、语音、图片输入的 AI 助手面板

## 一、先安装运行

本机当前环境里没有可直接使用的 `node/npm`，所以我没法在这里替你启动。但项目代码已经建好了。

你在这台电脑上装好 `Node.js 18+` 后，进入项目目录执行：

```bash
cd "d:\cursor做的APP\ai会议纪要"
npm install
npm run dev
```

启动后浏览器打开终端里显示的本地地址，一般会是：

```bash
http://localhost:5173
```

## 云端部署

这个项目已经补成适合 `Vercel` 云端部署的版本，关键文件是：

- `vercel.json`
- `.gitignore`
- `package.json` 中的 `node >= 18`

### 用 Vercel 部署

1. 把整个项目上传到你的 `GitHub` 仓库
2. 打开 [Vercel](https://vercel.com/)
3. 选择 `Add New Project`
4. 导入你的 GitHub 仓库
5. Vercel 会自动识别这是 `Vite` 项目
6. 保持默认设置，直接点击部署

部署成功后，Vercel 会给你一个公网网址。

这个网址可以直接发给别人，不同网络、不同城市、不同电脑都能打开。

### 为什么现在可以上云

- 项目是纯前端 Demo
- 构建产物是静态文件，适合直接托管
- `vercel.json` 已经处理了单页应用路由刷新问题

比如别人直接打开：

```bash
/todo
/knowledge
/analysis
/inventory
```

也不会因为刷新而报 404。

## 二、怎么使用这个 Demo

### 1. 首页

进入首页后，先看顶部和左侧导航。

- 点击 `解析总部新消息`
- 页面右侧手机预览区会显示“AI 正在解析消息”
- 约 1.5 秒后会自动新增一条待办任务
- 页面中部会出现 `任务接收动画演示`

这个动作对应 PPT 里的“把总部消息转发给小助手，AI 自动解析并整理待办”。

### 2. 待办任务

点左侧 `待办任务`：

- 左边会看到按类型分组的任务卡片
- 点击任意任务的 `去完成`
- 右侧会显示任务详情

你可以这样演示：

- 点击 `模拟图片识别回填`
  作用：把“图片识别后的字段结果”回填到任务补充内容中
- 点击 `模拟语音识别回填`
  作用：把“语音转写结果”回填到任务补充内容中
- 点击 `审核并提交`
  作用：当前任务状态会变成完成

如果要演示日报：

- 点击页面右上角 `查看日报弹窗`
- 会弹出 `今日工作简报`
- 里面会展示今日完成情况、剩余待办和 AI 建议

### 3. 我的知识库

点左侧 `我的知识库`：

- 上半部分可以直接改门店名称、店长、地址、电话、营业时间
- 下半部分可以切换模板并直接修改内容

建议这样演示：

- 把门店地址改掉
- 再去首页或 AI 助手里问“查看门店地址”
- AI 返回内容会读到新的门店信息

这就是知识库和其他模块的联动效果。

### 4. 经营分析

点左侧 `经营分析`：

- 点击 `今日 / 本月 / 本季度 / 本年`
- 上面的营收、订单量、客单价、增长率会变化
- 中间图表和热销排行也会变化
- 右侧 `AI 经营小结` 会跟着变化
- `运营策略` 和 `一周执行表` 也会同步展示

导出演示：

- 点击 `下载 PDF 报告`
  作用：下载销售分析 PDF
- 点击 `打印演示页`
  作用：直接打开浏览器打印窗口，适合做汇报演示

### 5. 采购管理

点左侧 `采购管理`：

- 上半部分看库存预警和库存表
- 低于阈值的项目会高亮显示
- 点击 `生成并下载采购清单`
  作用：下载 `CSV` 采购清单文件

右侧 `原材料查询` 可以演示自然语言查询场景：

- 输入 `招牌黄焖鸡`
- 页面会返回这个单品的主要原材料和当前缺货建议

### 6. AI 助手面板

每个页面底部都有 `AI 助手` 面板。

你可以这样用：

- 直接点快捷按钮：
  - `帮我总结今日经营情况`
  - `生成采购清单`
  - `更新门店地址`
  - `查看今日待办`
- 或者手动输入问题再点 `发送`
- 点击 `语音`
  - 如果浏览器支持语音识别，会尝试调用浏览器语音能力
  - 如果不支持，会自动走模拟转写逻辑
- 点击 `图片`
  - 上传一张图片后，AI 会返回模拟 OCR/图片识别结果

## 三、最适合汇报时的演示顺序

建议你按下面顺序讲：

1. 首页点击 `解析总部新消息`
2. 进入 `待办任务`，演示图片/语音回填和提交
3. 打开 `今日工作简报` 弹窗
4. 进入 `我的知识库`，修改门店信息
5. 用 `AI 助手` 提问门店信息，展示知识库联动
6. 进入 `经营分析`，切换时间维度并下载 PDF
7. 进入 `采购管理`，生成采购清单并下载

## 四、当前实现说明

- 数据使用本地 mock 数据
- 语音识别优先调用浏览器 `SpeechRecognition`，不支持时自动回退到模拟转写
- 图片上传后会返回模拟 OCR/识别结果
- 经营分析结论会根据当前所选时间周期动态生成
- 销售报告支持导出 `PDF`
- 采购清单支持导出 `CSV`
